## السجل

### Phase 3a — Master Data Foundation (QNEW-28/32/33/34) ✅ (هذا الكومِت)
الأساس الذي يعتمد عليه التسعير والتوزيع الآلي. حوّلنا القاموس الثابت لجداول حقيقية:
- **جداول (global، RLS: قراءة للكل/كتابة للـ platform):** `parts_master` (بمصدر إلزامي `source`)،
  `part_synonyms`، `part_category_mapping`. ميجريشن 0008 + RLS مخصّص 0009.
- **`cleanPartNumber()`** — أداة تنظيف موحّدة (QNEW-34): trim/upper/توحيد الفواصل لـ '-'.
- **detectCategory** (QNEW-33): كشف الفئة من الاسم/المرادف (EN/AR)؛ لا تطابق → matched:false (للمراجعة).
- **search** + **create/addSynonym** (أدمن). Endpoints تحت /api/parts.

**مُتحقَّق HTTP:** clean ("  br.12_345/67 " → "BR-12-345-67") · detect-category (disc pad/تيل → Brake) ·
مجهول → matched=false · بحث · إضافة قطعة+مرادف يُكتشف فورًا · الورشة تعدّل الماستر → 403.

**ملاحظة:** seed تمثيلي (قطعتان+مرادفات). ترحيل القاموس الكامل (615 مدخل من partDictionary.json)
= مهمة بيانات لاحقة عند الحاجة.
