# ADR-0005: Monorepo واحد (pnpm workspaces)

**الحالة:** مقبول — 2026-07-22 (اختيار صاحب المشروع)

## القرار
ريبو واحد: `apps/api` + `apps/web` + `packages/shared` + `infra` + `docs`.

## الأسباب
- مشاركة الأنواع والأدوار (`@qvm/shared`) بين الباك والفرونت بدون نشر حزم.
- تغيير واحد across-stack = PR واحد متزامن.
- أنسب لفريق صغير؛ إعداد CI واحد.

## البدائل المرفوضة
- **ريبوهات منفصلة:** فصل أوضح لكن تنسيق أصعب وتكرار إعدادات، ولا حاجة له بحجم الفريق الحالي.

## قيد العزل
هذا الريبو **منفصل تماماً** عن ريبو المشروع الحقيقي (`AhmedSHG97/qvm-new-production`) —
ريموت خاص، لا يُدفع له أي شيء من هنا، ولا يُسحب منه إلا نسخ ملفات UI معزولة (ADR-0006).
